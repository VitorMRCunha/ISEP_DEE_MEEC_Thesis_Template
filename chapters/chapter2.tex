No entanto salienta-se que, \underline{o \textit{template} é fornecido sem suporte} e que é da inteira responsabilidade do utilizador qualquer alteração ao código e/ou ficheiros fornecidos.

\section{Introdução ao \LaTeX{}}
\label{sec:Ch2.1}

O \LaTeX{} é uma poderosa ferramenta para produção de documentos. Ao contrário dos comuns processadores de texto como o Microsoft Word ou o LibreOffice Writer, o \LaTeX{} não é um programa \ac{wys}. Em vez disso, um documento escrito para \LaTeX{} é na verdade um simples ficheiro de texto sem qualquer tipo de formatação. Qualquer formato que se pretenda no documento final é definido através de comandos específicos que o \LaTeX{} interpreta aquando da compilação do documento. Por exemplo, para colocar uma palavra em itálico, no ficheiro de código escreve-se \verb|\textit{palavra}| para obter \textit{palavra} no documento final. Isso significa que o \LaTeX{} é uma linguagem \emph{markup}, à semelhança do \ac{html}. Desta forma o autor pode centrar-se na tarefa essencial da escrita, sem ter que se preocupar com formatações, paginação e outros arranjos visuais do documento em preparação. O \LaTeX{} é amplamente utilizado no meio académico para a elaboração e publicação de documentos científicos em várias áreas, incluindo matemática, estatística, engenharia, física, economia, entre muitas outras. Tem também um importante papel na preparação e publicação de livros.

Para quem está a começar com o \LaTeX{}, para além dos inúmeros \textit{websites} com informação (e.g., \url{www.overleaf.com/learn}), recomenda-se o livro gratuito intitulado ``Uma não tão pequena introdução ao \LaTeX{}'' disponível em \url{ftp.eq.uc.pt/software/TeX/info/lshort/portuguese/pt-lshort.pdf}. Este livro está também disponível em vários idiomas em \url{www.ctan.org/tex-archive/info/lshort/}.

\section{Como Usar o Template}
\label{sec:Ch2.2}

O \textit{template} encontra-se disponível e pronto a ser utilizado no Moodle do \ac{meec} (em ficheiro ZIP) e no \href{https://github.com/}{GitHub}. Pode ser utilizado diretamente num editor \textit{online} (e.g., Overleaf) ou compilado localmente, desde que estejam instalados uma distribuição \TeX{} atualizada e os pacotes necessários.
Em qualquer dos casos, antes de iniciar a escrita da dissertação, deverá familiarizar-se com a estrutura de diretórios e com os ficheiros fornecidos.

\subsection{Diretórios}

Os principais diretórios são os seguintes:

\begin{itemize}
     \item \textbf{chapters} -- contém os capítulos e os anexos da dissertação. Recomenda-se que cada capítulo ou anexo seja escrito num ficheiro \file{.tex} autónomo. Embora o número e a designação dos capítulos dependam do trabalho desenvolvido, deverão existir sempre um capítulo de ``Introdução'' e um capítulo de ``Conclusões''.

     \item \textbf{figures} -- contém as figuras utilizadas na dissertação. Recomenda-se uma nomenclatura coerente que permita associar facilmente cada ficheiro ao capítulo ou secção onde é utilizado.

     \item \textbf{front} -- contém os ficheiros para os elementos iniciais da dissertação: glossário, acrónimos, símbolos, dedicatória, agradecimentos, \textit{abstract} e listas iniciais. Poderá optar por não usar algumas destas secções caso não sejam relevantes para o seu documento.
\end{itemize}

\subsection{Ficheiros principais}

Além dos ficheiros criados automaticamente durante a compilação, o \textit{template} inclui os seguintes ficheiros relevantes:

\begin{itemize}
\item \textbf{main.tex} -- este é o ficheiro mais importante para a definição do seu documento. O código deste ficheiro define a estrutura e contém as instruções que levam o \LaTeX{} a gerar o PDF final. Tenha em consideração os comentários apresentados no próprio ficheiro por forma a saber o que faz cada linha/secção de código e de como o \textit{template} pode ser adaptado ao seu caso. É este ficheiro que deverá editar para dar como iniciada a elaboração da sua dissertação.

\item \textbf{DEEclass.cls} -- classe do documento que define o formato institucional. Não deve ser editado pelo estudante.

\item \textbf{preamble.tex} -- ficheiro destinado exclusivamente a \glspl{pack}, configurações e macros adicionais necessários ao documento. Desta forma evita-se que o preâmbulo do ficheiro principal \file{main.tex} fique demasiado extenso. 

\item \textbf{sampleRefs.bib} -- base de dados bibliográfica usada pelo Bib\LaTeX{}. Pode mudar o nome do ficheiro desde que essa alteração também seja feita no comando \verb|\addbibresource| do ficheiro \file{main.tex}. A lista bibliográfica e as citações são apresentada no PDF final segundo a configuração institucional.

\end{itemize}

\subsection{Configuração do ficheiro \file{main.tex}}
\label{subsec:Ch2.2.3}

A elaboração do seu documento deverá começar com a edição do ficheiro \file{main.tex}, que se encontra dividido em blocos claramente identificados. Para iniciar um novo documento, deverá editar apenas os campos de configuração e as inclusões de capítulos e anexos.

\subsubsection*{Definições principais}

Na secção \code{MAIN SETTINGS}, selecione uma das opções correspondentes ao ramo do \ac{meec}:

\begin{itemize}
\item \code{MEECAS} (\acs{meec} Automação e Sistemas)
\item \code{MEECSA} (\acs{meec} Sistemas Autónomos)
\item \code{MEECPI} (\acs{meec} Sistemas e Planeamento Industrial)
\item \code{MEECTE} (\acs{meec} Telecomunicações)
\end{itemize}

Selecione também o idioma principal do documento: 
\begin{itemize}
\item \code{portuguese} 
\item \code{english}
\end{itemize}

Quando o idioma selecionado é o português, o inglês é usado como segundo idioma nos elementos bilingues. Quando o idioma principal é o inglês, aplica-se a situação inversa.

As opções adicionais da DEEclass são:

\begin{itemize}
    \item \code{draft} -- modo de rascunho, útil durante a preparação do documento para tempos de compilação mais curtos;
    \item \code{finalversion} -- versão final, na qual são apresentados os elementos do júri das provas.
\end{itemize}

\subsubsection*{Dados da dissertação}

Na secção \code{DISSERTATION INFORMATION}, preencha obrigatoriamente:

\begin{itemize}
\item o título da dissertação;
\item o nome completo do candidato;
\item o número de estudante;
\item o nome e o endereço de correio eletrónico do orientador do \ac{isep}.
\end{itemize}

A data apresentada nas páginas iniciais do PDF gerado corresponde, por omissão, à data de compilação. Para fixar uma data específica, use o comando \verb|\subdate| no formato ISO \code{AAAA-MM-DD}.

O coorientador, a empresa e o orientador da empresa são opcionais. Quando não forem aplicáveis, os respetivos comandos devem permanecer comentados. A informação da empresa deve ser tratada de forma coerente: se for indicado o nome da empresa, deverá também ser indicado o orientador da empresa.

Os comandos relativos ao júri são necessários quando a opção \code{finalversion} da classe está ativa:
\begin{verbatim}
\committepresident{Nome do presidente, instituição}
\committeememberone{Nome do vogal, instituição}
\committeemembertwo{Nome do vogal, instituição}
\end{verbatim}

Se algum dos campos obrigatórios estiver em falta ou vazio, a compilação apresenta uma mensagem de erro que identifica o campo a corrigir. Esta validação pretende evitar a geração de versões finais com dados incompletos.

\subsubsection*{Declaração de integridade}

A declaração de integridade é gerada automaticamente pela classe do documento e incluída nas páginas iniciais do documento. O texto da declaração não deve ser removido ou editado manualmente e incorpora automaticamente: o nome e número do candidato, data de submissão e a indicação sobre a utilização, ou não, de ferramentas de inteligência artificial generativa (ver subsecção seguinte).

A responsabilidade pela veracidade da declaração e por todo o conteúdo apresentado na dissertação é exclusivamente do autor.

\subsubsection*{Declaração de uso de inteligência artificial generativa}
\label{subsec:ai-template}

Na secção \code{AI USAGE}, é obrigatório declarar se foram utilizadas ferramentas de inteligência artificial generativa:
\begin{verbatim}
\AIusage{no}
\end{verbatim}
ou
\begin{verbatim}
\AIusage{yes}
\end{verbatim}

Apenas os valores \code{yes} e \code{no} são aceites. Quando é usado \verb|\AIusage{yes}|, tornam-se obrigatórios três elementos adicionais:
\begin{enumerate}
    \item a identificação das ferramentas utilizadas;
    \item a seleção das formas de apoio prestado pela inteligência artificial;
    \item uma descrição da utilização de cada ferramenta.
\end{enumerate}

As ferramentas são indicadas através do comando \verb|\AItools| na forma de lista separada por vírgulas. Por exemplo:
\begin{verbatim}
\AItools{OpenAI ChatGPT, Microsoft Copilot}
\end{verbatim}

As formas de apoio são selecionadas através do comando \verb|\AIaids|. Os
identificadores disponíveis são:

\begin{tabularx}{\textwidth}{@{}l l X@{}}
(a) & \code{brainstorming}      & geração e exploração inicial de ideias; \\
(b) & \code{literature-search}  & apoio à pesquisa bibliográfica; \\
(c) & \code{translation}        & tradução de texto; \\
(d) & \code{summarization}      & resumo ou síntese de conteúdos; \\
(e) & \code{text-generation}    & geração de texto; \\
(f) & \code{text-review}        & revisão linguística ou estilística; \\
(g) & \code{code-generation}    & geração ou apoio à programação; \\
(h) & \code{visualization}      & produção ou apoio à criação de elementos visuais; \\
(i) & \code{data-analysis}      & apoio à análise de dados; \\
(j) & \code{other}              & outro tipo de utilização não incluído nas categorias anteriores. \\
\end{tabularx}
\newpage
Considere o seguinte exemplo de uso do comando \verb|\AIaids|:
\begin{verbatim}
\AIaids{
  brainstorming,
  literature-search,
  text-review,
  code-generation
}
\end{verbatim}

A descrição da utilização é escrita no ambiente \code{AItoolsdescription}. Cada utilização distinta deve ser introduzida com \verb|\item|. Para tornar a declaração concisa e factual, deve identificar a(s) ferramenta(s) através do número atribuído na lista de ferramentas, a(s) categoria(s) através da respetiva letra, o local da dissertação onde ocorreu a utilização e a finalidade concreta do apoio prestado. Quando aplicável, deverá também indicar de que forma o resultado produzido foi revisto, testado ou validado pelo autor. Considere os seguintes exemplos:

\begin{verbatim}
\begin{AItoolsdescription}
% One tool, one assistance category, at a specific location
\item Na Secção 2.3 foi utilizada a ferramenta (1) na categoria (b),
para sugerir palavras-chave e expressões de pesquisa relacionadas com
os temas abordados na revisão da literatura. As referências foram
posteriormente verificadas pelo autor nas fontes originais.

% One tool used for several assistance categories
\item No desenvolvimento do código MATLAB descrito no Capítulo 4 foi
utilizada a ferramenta (2) nas categorias (g) e (h), para gerar
funções auxiliares e apoiar a visualização gráfica dos resultados. 

% Several tools used for the same assistance category
\item Em toda a dissertação foram utilizadas as ferramentas (1) e (2
na categoria (e), para apoio à revisão linguística e melhoria da
clareza do texto. Todas as sugestões foram revistas pelo autor.

% One tool and category applied to several specific outputs/locations
\item A ferramenta (1) foi utilizada na categoria (d) nas Secções 3.2
e 3.4 e na discussão dos resultados da Secção 5.2, para resumir e
comparar informação proveniente das fontes bibliográficas previamente
selecionadas pelo autor.
\end{AItoolsdescription}
\end{verbatim}

Deste modo, a declaração estabelece uma correspondência direta entre a ferramenta utilizada, a categoria de utilização e a parte concreta da dissertação em que ocorreu essa utilização.

Quando a utilização de inteligência artificial é declarada, a classe gera automaticamente o anexo intitulado ``Declaração de Uso de Inteligência Artificial Generativa''. Este anexo inclui a informação declarada através dos comandos \verb|\AItools|, \verb|\AIaids| e ambiente \code{AItoolsdescription}.

A declaração do uso de inteligência artificial não transfere para as ferramentas usadas qualquer responsabilidade sobre o trabalho submetido a provas. Deve sempre verificar, corrigir e validar criticamente todo o conteúdo, código, análise, tradução ou referência obtidos com esse apoio.

\subsubsection*{Elementos iniciais e listas definidas pelo utilizador}

Na secção \code{USER DEFINED FRONTMATTER}, são carregadas as definições do glossário, acrónimos e símbolos. Os respetivos conteúdos são editados nos seguintes ficheiros:
\begin{itemize}
    \item \path{/front/0_glossary.tex} -- termos do glossário;
    \item \path{/front/0_acronyms.tex} -- acrónimos;
    \item \path{/front/0_symbols.tex} -- símbolos.
\end{itemize}

A dedicatória e os agradecimentos são opcionais. Para os incluir, edite os ficheiros correspondentes (\verb|/front/1_dedicatory.tex| e \verb|/front/2_acknowledgements.tex|) e mantenha ativos os comandos:
\begin{verbatim}
\IncludeDedication
\IncludeAcknowledgements
\end{verbatim}

Para omitir uma destas páginas, comente apenas o respetivo comando. Adicionalmente, o resumo/\textit{abstract} e as listas iniciais são carregados automaticamente pela classe:
\begin{itemize}
    \item \path{/front/3_abstract.tex} -- editar este ficheiro para introduzir o resumo da dissertação e as palavras-chave, em dois idiomas;
    \item \path{/front/4_frontmatterlists.tex} -- seleção das listas a apresentar no documento final, como a lista de figuras, tabelas, listagens, algoritmos, glossário, acrónimos e símbolos. Por exemplo, se na sua dissertação não fizer uso do glossário, basta comentar a correspondente linha no ficheiro \path{/front/4_frontmatterlists.tex}.
\end{itemize}

 
\subsubsection*{Compilação e ficheiros auxiliares}

Quando são usados Bib\LaTeX{}, glossários, acrónimos ou símbolos, o editor que está a usar para elaborar o seu documento tem também que executar as ferramentas auxiliares correspondentes, nomeadamente
\code{biber} e \code{makeglossaries}. Assim, depois de alterações estruturais importantes, pode ser necessário recompilar o documento duas ou mais vezes para atualizar referências cruzadas, índice, numeração, listas e marcadores do PDF.

\section{Formatos e Regras}
\label{sec:Ch2.3}

Uma das coisas mais importantes (e mais difíceis) de manter num documento longo como uma dissertação é a consistência. Assim, usar as seguintes regras e convenções permite produzir um documento técnicamente consistente que segue as regras definidas institucionalmente. Use o código fornecido neste ficheiro como base para a introdução das suas figuras, tabelas e restantes elementos.

\subsection{Glossário, acrónimos e símbolos}

Para ajudar o candidato a gerir as listas de termos específicos (\gls{gloss}), acrónimos e símbolos, o \textit{template} faz uso do \textit{package} \verb|glossaries|. Este permite, por exemplo, a ordenação alfabética das listas mencionadas e também que os acrónimos sejam descritos pelo menos uma vez no texto. As listas de termos, acrónimos e símbolos são definidas nos ficheiros mencionados na Subsecção~\ref{subsec:Ch2.2.3}. Tenha em consideração a informação presente nos comentários e os exemplos fornecidos, e de forma adicional na documentação do \gls{pack} disponível no endereço \url{ctan.org/pkg/glossaries} ou em \url{en.wikibooks.org/wiki/LaTeX/Glossary}.

No documento, para introduzir os termos definidos no glossário use o comando \verb|\gls{<tag>}|, onde \verb|<tag>| se refere ao identificador do termo definido no ficheiro \verb|0_glossary.tex|. O \textit{package} \verb|glossaries| disponibiliza comandos adicionais que permitem introduzir variações do termo originalmente definido, para tal consulte a documentação.

Para introduzir acrónimos ao longo do texto, o uso mais comum será através do comando \verb|\ac{<tag>}|, onde \verb|<tag>| se refere ao identificador do acrónimo definido no ficheiro \verb|0_acronyms.tex|. A primeira vez que o comando for usado é introduzida a versão completa (e.g., \ac{api}), e nas seguintes apenas será apresentado o acrónimo (e.g., \ac{api}). A Tabela~\ref{tab:acros} resume os principais comandos a ter em consideração.

\subsection{Referências}

O Bib\LaTeX{} é usado para formatar as referências bibliográficas e inserir citações como esta \cite{Gupta97} através do comando \verb|\cite{<Bibtexkey>}|. Alternativamente, para mencionar explicitamente o nome do(s) autor(es) na frase \textcite{Delorme1995}, usa-se o comando \verb|\textcite{<Bibtexkey>}|. As opções adotadas para a \verb|DEEclass| fazem com que as citações no texto sejam apresentadas como números entre parênteses retos. Citações múltiplas são separadas por vírgulas (e.g., \cite{Lipsum2008,Li2000,Candy1992}). Na correspondente secção da dissertação, as referências são ordenadas pela ordem de citação. 

Considere que as citações \cite{W3C2005,ATmega128A2019} devem ser colocadas antes dos sinais de pontuação \cite{Candy1992}, caso haja, como uma vírgula ou um ponto final \cite{IEA2024}. O mesmo se aplica a notas de rodapé\footnote{Como esta nota de rodapé, aqui em baixo.}.

\subsection{Listas}

Listas não numeradas são produzidas pelo ambiente \code{itemize}. Cada entrada da lista deve ser precedida pela sequência de controlo \code{\textbackslash item}. Por outro lado, as listas ordenadas são geradas pelo ambiente \code{enumerate} e cada entrada também deve ser precedida de \code{\textbackslash item}, que irá gerar automaticamente o rótulo dessa entrada. Os dois ambientes podem ser usados de forma encadeada.

\begin{enumerate}
   \item Primeiro nível lista ordenada
   \item Primeiro nível lista ordenada
   \begin{itemize}
     \item Segundo nível lista não ordenada
     \begin{itemize}
       \item Terceiro nível lista não ordenada
     \end{itemize}      
     \item Segundo nível lista não ordenada
     \begin{enumerate}
       \item Terceiro nível lista ordenada
       \item Terceiro nível lista ordenada
     \end{enumerate}    
   \end{itemize}
   \item Primeiro nível lista ordenada   
\end{enumerate}

\subsection{Figuras}

É desejável que a sua dissertação inclua figuras em quantidade e qualidade por forma a ilustrar as ideias que pretende transmitir. Todos os ficheiros de figuras devem ser colocados no diretório \path{/figures}. Para inserir as figuras no seu documento deve, regra geral, usar o código:

\begin{verbatim}
\begin{figure}[htbp]
	\centering
	\includegraphics[scale=0.8]{cap2_fig1.eps}
	\caption{Legenda com citação \parencite{Lipsum2008}.}
	\label{fig:exemplo1}
\end{figure}
\end{verbatim}

Este código produz a Figura~\ref{fig:exemplo1}. As figuras podem ser redimensionadas de uma forma absoluta através da opção \code{scale}, ou de forma relativa, e.g., à largura da área de texto da forma: \path{\includegraphics[width=0.5\textwidth]{cap2_fig1.eps}}. Se necessário pode também recorrer a sub-figuras (ver código deste ficheiro), como demonstrado pela Figura~\ref{fig:exemplo2} que contém as sub-figuras~\ref{fig:subfigA} e~\ref{fig:subfigB}.

\begin{figure}[htbp]
	\centering
	\includegraphics[scale=0.8]{cap2_fig1.eps}
	\caption{Legenda com citação \parencite{Lipsum2008}.}
	\label{fig:exemplo1}
\end{figure}

\begin{figure}[htbp]
  \centering
  \subcaptionbox{Uma sub-figura\label{fig:subfigA}}{\includegraphics[width=0.45\linewidth]{cap2_fig1.eps}}
%  \hfill
  \subcaptionbox{\label{fig:subfigB}}{\includegraphics[width=0.45\linewidth]{cap2_fig1.eps}}
  \caption[Uma figura com duas sub-figuras.]{Uma figura com duas sub-figuras: (a) com legenda e (b) sem legenda.}
  \label{fig:exemplo2}
\end{figure}

Tenha em consideração que nem sempre as figuras irão aparecer no ponto onde escreveu o código, dado que o posicionamento depende do espaço disponível na página. Posicionar as figuras é trabalho para o \LaTeX{} e por isso só se deve preocupar em fazer as imagens, de preferência em formato vetorial (e.g., EPS, PDF). O \LaTeX{} por omissão aceita os formatos PDF, JPG e PNG. As figuras devem ser sempre referidas no texto e devem também ter sempre uma legenda, definida através do comando \verb|\caption{}|. Não esquecer que quando uma figura é obtida de uma referência bibliográfica, i.e., não é da sua autoria, esse facto deve ser mencionado (ver legenda da Figura~\ref{fig:exemplo1}).

Este \textit{template} disponibiliza o comando adicional \verb|\inlinegraphics| que permite inserir figuras na linha de texto. Este é um exemplo \inlinegraphics{Inlinefigureexample.png}. Por vezes uma figura necessita de ser apresentada em \textit{landscape}, onde a Figura~\ref{fig:exemplo3} é um exemplo desta forma de apresentação.

\subsection{Tabelas}

As tabelas são uma forma importante de apresentação de informação. A Tabela~\ref{tab:basictable} ilustra a aplicação das principais diretrizes a ter em consideração na construção de tabelas:

\begin{enumerate}
   \item Não usar linhas verticais.
   \item A legenda é colocada antes da tabela.
   \item Usar as macros \verb|\toprule|, \verb|\midrule| e \verb|\bottomrule| para criar as linhas horizontais, respetivamente, do topo, meio e fundo da tabela.
\end{enumerate} 

Considere o seguinte código usado para criar a Tabela~\ref{tab:basictable}:

{\small
\begin{verbatim}
\begin{table}
\caption{Exemplo de uma tabela simples em \LaTeX{}.}
\label{tab:basictable}
\centering

\subsection{Algoritmos e excertos de código}

A apresentação de algoritmos na forma de pseudo-código é útil para apresentar uma dada lógica independentemente da linguagem em que esta irá ser implementada. O Algoritmo~\ref{alg:exemplo} é um exemplo criado com os comandos do \textit{package} \verb|algorithmicx|. 

\begin{algorithm}[hbt!]
\caption{Exemplo de um algoritmo}
\label{alg:exemplo}
\hrulefill
\begin{algorithmic}[1]
\State $i \gets 10$
\If{$i\geq 5$} 
    \State $i \gets i-1$ 	\label{alg:line:l3}
\Else
    \If{$i\leq 3$}
        \State $i \gets i+2$ \Comment{Isto é um comentário}
    \EndIf
\EndIf 
\end{algorithmic}
\hrulefill
\end{algorithm}

Irá encontrar na documentação (\url{https://ctan.org/pkg/algorithmicx}) deste \textit{package} a lista completa de comandos disponíveis para criar os mais comuns ciclos e estruturas de controlo de fluxo lógico. É também possível fazer referência a linhas específicas do algoritmo, e.g., ver código da linha~\ref{alg:line:l3}.

Para apresentar excertos de código-fonte na sua dissertação este \textit{template} usa o \gls{pack} \verb|listings|. Tenha em consideração que por omissão as listagens estão definidas como flutuantes para que o \LaTeX{} as possa posicionar da melhor forma. Esta definição implica também que uma listagem não será dividida por uma nova página, pelo que é recomendado que utilize excertos que não excedam uma página. Existem muitas opções que podem ser especificadas neste ambiente, para mais informações consultar \url{https://en.wikibooks.org/wiki/LaTeX/Source_Code_Listings}.

O comando \verb|\printlistoflistings|, invocado no ficheiro \path{4_frontmatterlists.tex}, cria a secção ``Listagens'' na sua dissertação. Assim, se não usar listagens na sua dissertação deverá comentar este comando. A Listagem~\ref{lst:examplo1} e a Listagem~\ref{lst:examplo2} são dois exemplos de listagens de código. import numpy as np
    
def incmatrix(genl1,genl2):
    m = len(genl1)
    n = len(genl2)
    M = None #to become the incidence matrix
    VT = np.zeros((n*m,1), int)  #dummy variable
    
    #compute the bitwise xor matrix
    M1 = bitxormatrix(genl1)
    M2 = np.triu(bitxormatrix(genl2),1) 

    for i in range(m-1):
        for j in range(i+1, m):
            [r,c] = np.where(M2 == M1[i,j])
            for k in range(len(r)):
                VT[(i)*n + r[k]] = 1;
                VT[(i)*n + c[k]] = 1;
                VT[(j)*n + r[k]] = 1;
                VT[(j)*n + c[k]] = 1;
                
                if M is None:
                    M = np.copy(VT)
                else:
                    M = np.concatenate((M, VT), 1)               
                VT = np.zeros((n*m,1), int)  
    return M
\end{lstlisting}

\subsection{Equações}

Se a sua tese fizer uso de conteúdo matemático, então a opção de usar o \LaTeX{} foi a mais acertada. O livro ``Uma não tão pequena introdução ao \LaTeX{}'' tem informação suficiente para a maioria dos casos de composição matemática, mas para conteúdos mais completos recomenda-se o guia \url{tug.ctan.org/info/short-math-guide/short-math-guide.pdf}. Adicionalmente, uma extensa lista de símbolos pode ser consultada em \url{tug.ctan.org/info/symbols/comprehensive/symbols-a4.pdf}.

O \LaTeX{} permite a escrita de equações \textit{inline} como $E = mc^{2}$ ou em modo \textit{display}, sendo neste caso automaticamente numeradas. Deverá usar o comando \verb|\label{<label>}| para fazer referência a uma equação~(\ref{eqn:einstein}). O código:

\begin{verbatim}
\begin{equation}
	E = mc^{2} .
	\label{eqn:einstein}
\end{equation}
\end{verbatim}

\noindent produz a famosa equação:

\begin{equation}
E = mc^{2} .
\label{eqn:einstein}
\end{equation}

Para apresentar sistemas de equações recomenda-se o uso do ambiente \code{align}:
\begin{align}
	x_1 &= x_2 + x_3\\
	y_1 + y_2 &= z_1 + z_2
	\label{eqn:eq2}
\end{align}
